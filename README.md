# Asset Store Hover Preview

Tampermonkey-скрипт для быстрого предпросмотра страниц ассетов непосредственно на форуме. Достаточно задержать указатель на названии ассета — рядом появится карточка с изображениями, названием, ценой и описанием товара.

[![Установить в Tampermonkey](https://img.shields.io/badge/Установить_в_Tampermonkey-00485B?style=for-the-badge&logo=tampermonkey&logoColor=white)](https://raw.githubusercontent.com/krazzer00/asset-store-hover-preview/main/asset-link-hover-preview.user.js)

## Возможности

- предпросмотр по наведению без открытия новой вкладки;
- до четырёх изображений из галереи товара;
- название, цена и краткое описание;
- фоновая предзагрузка найденных ссылок;
- сначала загружаются ссылки, видимые на экране;
- кэширование результатов без повторных запросов;
- поддержка динамически добавляемых ссылок;
- автоматическое исключение `DL`-ссылок и популярных файлообменников;
- автоматические обновления через Tampermonkey;
- закрытие карточки при прокрутке страницы или по клавише `Esc`.

## Поддерживаемые магазины

Скрипт проверен с Jinxxy, Gumroad, Payhip и магазинами Payhip на собственных доменах. Также предусмотрена поддержка:

- Booth;
- Ko-fi;
- itch.io;
- Sellfy;
- Fourthwall;
- VRModels;
- других сайтов с Open Graph, Twitter Card или Product JSON-LD.

## Установка

### Быстрый способ

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для Chromium-браузера.
2. Нажмите кнопку **«Установить в Tampermonkey»** в начале README.
3. В открывшемся окне Tampermonkey нажмите **«Установить»**.
4. Обновите страницу форума.

Все необходимые права уже указаны в метаданных userscript и подключаются во время установки. Отдельно добавлять сайт форума или домены магазинов в настройках Tampermonkey не требуется. Chromium не разрешает сайтам выдавать расширениям права полностью без участия пользователя, поэтому единственное обязательное действие — подтверждение на экране установки.

### Ручной способ

1. Откройте файл [`asset-link-hover-preview.user.js`](./asset-link-hover-preview.user.js).
2. Скопируйте его содержимое.
3. Нажмите значок Tampermonkey → **«Создать новый скрипт»**.
4. Удалите шаблон, вставьте код и сохраните через `Ctrl+S`.

## Использование

Задержите указатель на названии ассета примерно на 0,4 секунды. Если карточка уже была загружена в фоне, она появится практически мгновенно.

Обычный клик по ссылке продолжает работать. Ссылки с подписью `DL`, Google Drive, Mega, MediaFire, PixelDrain и другие файлообменники намеренно пропускаются.

## Предзагрузка

Через 0,9 секунды после открытия страницы скрипт собирает подходящие ссылки. Видимые обрабатываются первыми, затем остальные переходят в фоновую очередь.

Одновременно выполняется не более трёх запросов. Предзагрузка автоматически отключается при включённой экономии трафика или соединении уровня 2G.

## Настройки

Параметры находятся в объекте `CONFIG` в начале скрипта:

| Параметр | Назначение |
|---|---|
| `hoverDelayMs` | Задержка перед появлением карточки |
| `requestTimeoutMs` | Тайм-аут загрузки страницы магазина |
| `maxImages` | Максимум изображений в карточке |
| `previewAllExternalLinks` | Предпросмотр всех внешних ссылок либо только известных магазинов |
| `prefetchEnabled` | Включение фоновой предзагрузки |
| `prefetchStartDelayMs` | Задержка перед началом предзагрузки |
| `prefetchConcurrency` | Число одновременных фоновых запросов |
| `maxPrefetchLinks` | Максимальное число заранее загружаемых ссылок |

## Разрешения и приватность

Скрипт использует `GM_xmlhttpRequest`, чтобы прочитать публичные метаданные страниц магазинов. Данные не отправляются на сторонний сервер и не сохраняются между сессиями браузера. Файлы ассетов не скачиваются.

Некоторые магазины могут блокировать автоматическое чтение страницы или не публиковать изображения в метаданных. В таком случае появится сообщение, что предпросмотр недоступен, а обычная ссылка продолжит работать.
